### Fix Crítico: Carga de Puntos en App Móvil

**Problema identificado**:
```javascript
// ❌ ANTES - Campo incorrecto
const user = JSON.parse(userData);
setUserPoints(user.puntos_totales || 0); // Este campo no existe
```

**Solución aplicada**:
```javascript
// ✅ DESPUÉS - Obtiene datos frescos del API
const userResponse = await fetch(`http://10.219.126.3:3307/api/users/${user.id}`, {
    headers: { Authorization: `Bearer ${token}` }
});
const currentUser = await userResponse.json();
setUserPoints(currentUser.puntos || 0);
```
